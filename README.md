# Arafath Shafin Portfolio

Material 3 Expressive-inspired portfolio for video editing work, built with React, Vite, and Bun-compatible scripts.

## Run locally

```bash
npm install
npm run dev
```

If Bun is installed:

```bash
bun install
bun run dev
```

## Add videos later

Update the project data in `src/main.jsx` with real YouTube URLs and thumbnails when the videos are ready.
